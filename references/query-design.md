# 检索词构造与迭代

## 第零步：社科检索偏好

1. **理论文献优先搜「源头」**：理论原典、权威理论综述 / 手册、该理论领域公认专家的代表作优先；找到一个理论后，顺着引文追踪看它后来怎么被使用、修正和挑战，而不是只追着二手转述跑。**权威性是入口信号，不代替命题适配性**——找到权威来源后仍要核它的命题和你的问题对不对得上。
2. **权威学者与权威期刊优先作为发现入口**：从一个领域绕不开的学者（其代表作 + 引用谱系）和公认核心期刊（英文 SSCI 刊、中文 CSSCI / 核心期刊）入手，能快速摸到领域主干。但期刊层级、引用数、检索排序**只用于发现与排序提示，不作纳入 / 排除依据**——小期刊上直接相关的研究照样重要，低频反例可能不可替代。
3. **按问题选资料类型**。理论题可查专著和手册章节。经验研究或政策题若需要尚未正式发表的结果、地方经验或执行情况，可补查工作论文、学位论文、政府文件或机构报告。
4. **中英文分开设计**：中文库（知网等）和英文库（WoS 等）用词体系不同，分别构造检索词，不做字面直译；中文注意学界通用译法与本土表达的差异。

## 第一步：确定检索概念

先从研究问题里找出研究对象、暴露或干预、结果和情境，再分别列出检索词。

| 检索概念 | 内容 | 示例（分娩创伤与后续生育） |
| --- | --- | --- |
| 对象 | 人群 / 样本 | 育龄女性、经产妇 |
| 暴露 / 干预 | 核心经历或处理 | 分娩创伤、产后 PTSD |
| 结果 | 关注的结果阶段 | 生育意愿、生育间隔、再次活产 |
| 情境 | 时间 / 地点 / 制度 | 产后随访期、中国情境 |

「生育意愿」「生育间隔」和「再次活产」衡量的结果不同。分别列词，后续筛选和解读时也要区分。

## 第二步：同义扩展

为同一概念整理各语言里的不同说法。上下位概念、相邻概念、解释机制和不同结果要先分清，再决定是否单独试搜。

1. **同义 / 近义词**：如 childbirth trauma / traumatic birth / birth trauma；
2. **上下位词**。如用 postpartum PTSD 查具体经历，用 maternal mental health 补查范围更广的研究，分别记录命中。
3. **相邻学科术语**：人口学、心理学、护理学、公共卫生对同一构念的叫法不同，都要试；
4. **中英文分别拟词**。中文从本土研究和制度用语找词，英文从相应学科的术语和索引找词。

## 第三步：布尔组合

- 用 OR 连接同一概念的不同说法。主检索式只用 AND 连接回答问题所必需、且能在数据库中稳定检出的概念。如果数据库对研究对象或情境的标注不一致，可以在筛选文献时再判断。
- 例如先用「分娩创伤词组 AND 后续生育词组」试搜，再按生育意愿、生育间隔、再次活产分别补检。增减一组检索词时，用已知相关文献检查会多找到或漏掉哪些文献。
- 逐平台适配主题词、字段、截词与过滤语法。记录平台、日期、原样检索式（含字段与过滤条件）及显示命中量。平台未提供总数时，记录实际查看或导出数和查看范围。

## 第四步：迭代规则

| 情况 | 动作 |
| --- | --- |
| 命中量过大（粗筛不可行） | 试调字段或加入符合检索方案的限制条件，先检查会丢掉哪些已知相关文献 |
| 命中量过小（明显漏检） | 放宽限定、换相邻学科术语、补同义词 |
| 关键已知文献未被命中 | 先确认该库是否收录、该文献是否符合检索范围，再检查词表、字段、过滤条件和查看范围 |
| 换了词但结果集几乎不变 | 记录后停止该方向迭代，转引文追踪 |

每次调整后，记下改了哪些词、为什么改，以及调整前后的命中数。

## 中文检索特别提示

- 中文来源的获取往往依赖平台内检索 + 网页补检 + 人工权限下载的组合，单一插件难以稳定覆盖知网条目、CAJ 格式和权限页面；
- 中文关键词需要单独迭代：先试学界通用译法，再试本土表达；
- 记录中文全文的格式（PDF、CAJ 或网页）。CAJ 有时需要人工转换，才能提取正文。
